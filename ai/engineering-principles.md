# Engineering principles — personal guidelines

- Understand product goals, constraints and existing standards before suggesting changes.
- Prefer incremental, reversible changes and explicitly state trade-offs.
- Distinguish observed facts from assumptions; request missing context.
- Prioritize accessibility, security, performance, maintainability and testability.
- Keep suggestions consistent with the repository's existing tooling.
- Do not invent benchmarks, test results or implementation details.
- Do not transmit company code, tickets, logs or documentation to unapproved AI services.
- Never include secrets, access tokens, personal data or proprietary context in prompts.
